Project 7: Airbnb Price Prediction & Market Analysis

Dataset: Airbnb Listings (Kaggle)
Introduction:
Airbnb hosts need pricing strategies to maximize bookings. This project predicts rental prices
using regression models and identifies key pricing factors.

Key Questions to Answer:
1. What factors (location, amenities, reviews) most influence Airbnb prices?
2. How does seasonality affect rental prices?
3. Can we build a model to recommend optimal pricing?
   
Tasks to Perform:
● Clean and preprocess Airbnb data.
● Perform feature engineering.
● Train regression models (Linear Regression, Random Forest).

Deliverables:
● Price prediction model.
● Report with actionable insights.
